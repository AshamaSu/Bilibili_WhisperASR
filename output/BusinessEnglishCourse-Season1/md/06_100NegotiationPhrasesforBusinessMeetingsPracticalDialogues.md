## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| We're going to learn how to use negotiation phrases in business meetings. | 我们要学的是如何在商务会议中运用谈判用语。 |
| For example, does this timeline work for you? | 比如，这个时间安排你方便吗？ |
| Then you can say, let's continue this discussion later, or I think we need more time to review. | 这时你可以说"我们稍后再继续讨论"，或者"我想我们需要更多时间评估"。 |
| Now let's talk about compromise. | 现在我们来谈谈折中。 |
| Currently, the deadline is very tight. | 目前截止日期非常紧。 |
| Would there be flexibility with bonuses or benefits? | 奖金或福利方面还有弹性空间吗？ |
| A counter offer is when you respond with a different offer. | "还价"就是你用一个不同的报价来回应。 |
| Stay calm and respectful. | 保持冷静和尊重。 |
| Yes, good negotiation is about collaboration, not conflict. | 是的，好的谈判靠的是合作，而不是冲突。 |
| Speaking of that, how do we disagree in a professional way? | 说到这，我们如何专业地表达不同意？ |
| I'll be a client and you'll be a project manager. | 我来扮演客户，你来扮演项目经理。 |
| For example, I see it a bit differently. | 比如说：我的看法稍微有些不同。 |
| That sounds like a good compromise. | 听起来是个不错的折中方案。 |
| I see your point. | 我明白你的意思。 |
| We're willing to be flexible on X if you can adjust Y. | 如果你们能调整 Y，我们愿意在 X 上灵活处理。 |
| Would you be open to adjusting this slightly? | 您是否愿意稍微调整一下这里？ |
| Or could you explain that in more detail? | 或者，您能再详细解释一下吗？ |
| Another one is just to make sure I understand. | 另一句是为了确认我理解无误。 |
| Practice these phrases out loud. That's how you build confidence. | 大声练习这些句子——自信就是这样练出来的。 |
| But actually, it's about communication, understanding, and compromise. | 但其实，谈判靠的是沟通、理解和折中。 |
