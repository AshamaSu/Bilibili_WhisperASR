## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| Today, we're going to crack the code on corporate speak. | 今天我们来破解企业黑话。 |
| We have to start with the most common one of all, touch base. | 我们得从最常见的一个开始：touch base（对一下情况）。 |
| In the office or in a professional email, you're going to want to say, assist. | 在办公室或正式邮件里，你会想说 assist（协助）。 |
| Look at the formal versions, continue, postpone, investigate. | 看这些正式版本：continue、postpone、investigate。 |
| It's using the formal word in an informal situation, which is a mistake in itself. | 在非正式场合用正式词，本身就是一种错误。 |
| That feels like the number one rule of corporate life. Don't surprise the boss. | 这像是职场第一法则：别让老板措手不及。 |
| They expect you to hit the ground running. | 他们指望你上手就能出活。 |
| Let's get some quick, easy wins to build momentum before we tackle the big stuff. | 先拿几个快赢建立势头，再攻难的。 |
| This is a bit off track, let's take it offline. | 这有点跑偏了，我们会下单独聊。 |
| It's back to the drawing board. | 又得推倒重来了。 |
| It's the idea that one plus one doesn't just equal two, it equals three. | 意思是一加一不只是二，而是三。 |
| It's a way to build momentum by knocking out the simplest tasks first. | 这是先解决最简单的任务来积攒势头的做法。 |
| The Germanic phrasal verb gets replaced by the single, efficient Latinate verb. | 日耳曼语的短语动词会被单个高效的拉丁语系动词替代。 |
| It means timely, concise updates. Think bullet points. | 意思是及时、简洁的进展通报，想象成要点列表。 |
| You move that conversation to a follow-up email. | 你把那段对话挪到后续邮件里继续。 |
| You stay in the loop, so nothing surprises you. | 你保持在知情范围内，就不会被突发情况打到。 |
| A leader who only talks about low-hanging fruit probably lacks a long-term vision. | 只谈容易摘的果子的领导，多半缺乏长期视野。 |
| Number nine has a really important nuance, buy versus purchase or acquire. | 第九条有个很重要的细微差别：buy 与 purchase、acquire 之别。 |
