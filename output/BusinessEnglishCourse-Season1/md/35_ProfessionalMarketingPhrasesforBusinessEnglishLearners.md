## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| The main goal is to drive awareness and generate qualified leads. | 主要目标是提升知名度、获取有效线索。 |
| Does that align with what you've seen in the materials? | 这和你看到的材料一致吗？ |
| Do we have a clear owner for each type? | 每类内容都有明确的负责人吗？ |
| If anything is delayed, we need to know immediately. | 任何延误都要第一时间上报。 |
| If CTR is below benchmark, we tweak copy or targeting immediately. | 点击率低于基准，就立刻调整文案或定向。 |
| Let's map dependencies in a visual timeline. | 把任务依赖关系放进可视化时间线。 |
| Any changes after that require leadership sign off. | 之后任何改动都需要管理层签字确认。 |
| We should schedule a pre-launch rehearsal. | 我们应该安排一次上线前彩排。 |
| Two weeks after launch, we hold a full retrospective. | 上线两周后，我们做一次完整复盘。 |
| Make sure there's a review process. | 一定要有内容审核流程。 |
| Delays at this stage can cascade into other channels. | 这个阶段的延误会在其他渠道连锁放大。 |
| Let's make this launch smooth and impactful. | 让这次发布平稳而有影响力。 |
| Messaging consistency is critical across channels. | 各渠道的传播口径一致至关重要。 |
| Everyone should tag themselves for accountability. | 每个人认领任务时都要署名，确保责任到人。 |
| Clear escalation reduces confusion. | 明确的上报路径能减少混乱。 |
| Discipline is as important as planning. | 执行纪律和计划本身同样重要。 |
