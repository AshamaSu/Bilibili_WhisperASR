## 2. 句式

| 句式 | 使用场景 | 原文例句 |

| I am writing to request… | 开门见山提请求 | Say, I am writing to request a meeting… |

| I am writing to update you on… | 汇报进展 | I am writing to update you on the project. |

| Please let me know if this is possible. | 请求确认/答复 | Please let me know if this is possible. |

| Try to find the name if possible. | 细节建议 | …but try to find the name if possible. |

## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| That's right. Today, we're talking about how to write a professional email in business English. | 没错。今天我们讲的是如何用商务英语写一封专业邮件。 |
| A professional email is a clear, polite, and well-structured message used in formal or… | 专业邮件是一封清晰、礼貌、结构良好的信息，用于正式或…… |
| The first part is the subject line. | 第一部分是邮件主题行。 |
| Now let's move to the next part, the greeting. | 现在进入下一部分：称呼语。 |
| And professional greetings include Dear Mr. Smith, Dear Ms. Brown, or Dear Team. | 专业的称呼包括 Dear Mr. Smith、Dear Ms. Brown 或 Dear Team。 |
| You can say Dear Sir or Madam, but try to find the name if possible. | 你可以写"敬启者"，但尽量找到对方的姓名。 |
| Then you can say, Dear Sir or Madam, or Dear Hiring Manager. | 这时你可以写 Dear Sir or Madam，或 Dear Hiring Manager。 |
| Dear Ms. Brown, I hope you are doing well. | 尊敬的 Brown 女士：见信安好。 |
| Say, I am writing to request a meeting, or I am writing to inform you about the project. | 可以写：I am writing to request a meeting（特此申请开会），或 I am writing to inform you about the project（特此告知项目情况）。 |
| I am writing to update you on the project. | 特此向你同步项目的最新进展。 |
| Could you please send me the file? | 能麻烦您把文件发给我吗？ |
| Please let me know if this is possible. | 如果可行，请告知我。 |
| …and then add details, are you available on Monday or Tuesday? | ……然后补充细节：您周一或周二有空吗？ |
| Instead of saying, this is unacceptable… | 别直接说"这不可接受"…… |
| Yes, keep your sentences short and clear. | 是的，句子要简短清晰。 |
| One idea per paragraph. | 一段只讲一个要点。 |
| Not checking grammar and spelling. | （常见错误是）不检查语法和拼写。 |
| Looking forward to your reply. | 期待您的回复。 |
| Thank you again. | 再次感谢。 |
| Common closings include best regards, kind regards, or sincerely. | 常用的结尾敬语有 best regards、kind regards 或 sincerely（谨启）。 |
| Subject. Re: Project Update. Dear Sarah, thank you for the update. The progress sounds great. | 主题：回复：项目进展。亲爱的 Sarah：感谢你的更新，进展听起来很顺利。 |
| Hi everyone. Thanks for joining us. | 大家好，感谢收听。 |
| Now let's do a role play. | 现在我们来做个角色扮演。 |
