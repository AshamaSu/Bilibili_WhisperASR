## 2. 句式

| 句式 | 使用场景 | 原文例句 |
|---|---|---|
| I see your point, but I think we should review the numbers first. | 会议中先认可再反对 | I see your point, but I think we should review the numbers first. |
| Instead of saying…, what should we say? | 引出更得体的说法 | So instead of saying, help me, what should we say? |
| Then follow with a solution. | 带着方案提问题 | Then follow with a solution, let's find a solution. |
| Could you update the report? | 委派/请求配合 | Also, could you update the report? |
| What are we talking about today? | 会议开场 | So Jack, what are we talking about today? |
| We should improve communication. | 提出改进建议 | We should improve communication. |
| We're working on resolving it. | 汇报问题处理中 | …but we're working on resolving it. |
| It shows you value the other person's time. | 解释为何这样表达 | It shows you value the other person's time. |
| We should focus on improving customer experience. | 表达观点 | …we should focus on improving customer experience. |
| That sounds like a good idea. | 认可提议 | That sounds like a good idea. |

## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| Today we're diving into a very practical and powerful topic, workplace communication. | 今天我们深入聊一个非常实用有力的话题：职场沟通。 |
| Okay, everyone, let's get started. | 好了各位，我们开始吧。 |
| Now let's move to asking for help. | 现在我们进入"求助"这个话题。 |
| I see your point, but I think we should review the numbers first. | 我明白你的意思，但我觉得我们应该先核对一下数据。 |
| So instead of saying, help me, what should we say? | 那么，与其说"帮帮我"，我们该怎么说？ |
| Then follow with a solution, let's find a solution. | 然后跟上解决方案——我们来找个办法。 |
| Could you update the report? | 你能更新一下报告吗？ |
| So Jack, what are we talking about today? | 那么 Jack，我们今天聊什么？ |
| We should improve communication. | 我们应该改进沟通。 |
| …but we're working on resolving it. | ……但我们正在着手解决。 |
| It shows you value the other person's time. | 这表明你尊重对方的时间。 |
| We should focus on improving customer experience. | 我们应该专注于提升客户体验。 |
| That sounds like a good idea. | 听起来是个好主意。 |
