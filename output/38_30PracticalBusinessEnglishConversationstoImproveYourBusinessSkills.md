## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| We need to focus on containment, communication, and recovery. | 我们要聚焦在控制事态、沟通和恢复上。 |
| Silence or vague communication will only fuel speculation. | 沉默或含糊其辞只会助长猜测。 |
| People need clarity, even if the message is that the situation is evolving. | 即便情况还在变化，也要把话说清楚。 |
| I'd like to suggest setting up a crisis task force. | 我建议成立一个危机专项小组。 |
| However, assigning blame during an ongoing crisis is counterproductive. | 不过，危机进行中追究责任只会适得其反。 |
| From a compliance standpoint, regulatory notification should be our first priority. | 从合规角度看，向监管报备应是第一优先。 |
| That's a valid concern, but compliance obligations must come first. | 这个顾虑有道理，但合规义务必须优先。 |
| We should prepare for worst case outcomes. | 我们要为最坏情况做准备。 |
| Dwelling too much on worst case scenarios can distract teams from immediate priorities. | 过度纠结最坏情况会让团队偏离当务之急。 |
| In crisis management, credibility comes from doing what you say you will do. | 危机管理中的可信度，来自说到做到。 |
| Then our objective should be not merely to survive this situation, but to emerge better. | 那我们的目标就不只是挺过去，而是要变得更好。 |
| With coordinated effort, we can regain stability and trust. | 只要协同行动，我们就能重获稳定与信任。 |
| Acknowledgement, corrective action, and consistency over time. | 承认问题、采取纠正措施，并长期保持一致。 |
| The message should acknowledge the disruption and outline the steps we're taking. | 这份声明应承认造成的中断，并说明我们正在采取的步骤。 |
| History is full of companies that survived breaches. | 历史上有许多公司从数据泄露中挺了过来。 |
| A task force would allow us to act quickly while maintaining oversight. | 专项小组能让我们快速行动，同时保持监督。 |
