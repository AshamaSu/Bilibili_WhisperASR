## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| We need to align on scope, timelines and key outcomes before we announce anything. | 对外公布之前，我们得把范围、时间线和关键成果对齐。 |
| It's not just a rubber stamp. | 这不只是走个过场盖个章。 |
| They signal, OK, if we cross this line, we have to stop and immediately check in with the executive sponsor. | 它们传达的信号是：一旦越线，必须停下来立刻找高管发起人确认。 |
| They commit to vetting data handling and access controls before they lock in the architecture. | 他们承诺在定下架构之前先审数据处置和访问控制。 |
| Technical governance is about ensuring quality over speed. | 技术治理讲的是质量优先于速度。 |
| It's confirming that the team cannot proceed without external intervention. | 它确认的是：没有外部介入，团队就无法推进。 |
| The earlier a blocker is surfaced, the cheaper and easier it is to fix. | 卡点暴露得越早，修起来越便宜越容易。 |
| You are reporting an objective deviation that requires sponsor intervention. | 你报告的是一个需要发起人介入的客观偏差。 |
| The goal is to make the process objective, not personal. | 目标是让事情对事不对人。 |
| This preserves psychological safety. | 这能保住心理安全感。 |
| It rules all subjectivity. | 它把主观因素全部排除。 |
| Does the test coverage report show a minimum of 85% coverage? | 测试覆盖率报告显示达到 85% 下限了吗？ |
| It means it satisfies all of those criteria, not just the coding part. | 意思是所有标准都满足了，不只是写完代码。 |
| They also track the burn rate against the plan weekly. | 他们还每周对照计划追踪预算消耗速度。 |
| Flagging variances early allows them to course correct. | 尽早标出偏差，才能及时纠偏。 |
| It's not, are we feeling good about the code? | 不是问「我们对代码感觉还不错吧」。 |
