## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| We appreciate the opportunity to discuss this proposal in detail. | 感谢有机会详细讨论这份方案。 |
| We're open to discussing volume, but we need clarity on what kind of commitment would justify it. | 采购量可以谈，但要先明确什么样的承诺量才撑得起这个价。 |
| Ideally, we're looking at a minimum 10% reduction to justify the switch. | 理想情况下，至少要降 10% 我们才值得换供应商。 |
| That's reasonable. | 这很合理。 |
| I appreciate the flexibility, but I need to be honest. | 感谢你们的弹性，但我得说实话。 |
| If you can provide rolling forecasts, it would help us manage inventory. | 如果你们能提供滚动预测，会有助于我们管理库存。 |
| Our standard policy is 60 days credit. | 我们的标准政策是 60 天账期。 |
| We can include a service penalty clause if that level isn't met. | 如果达不到这个水平，我们可以加入服务罚则条款。 |
| Our aim is to be transparent and flexible so we can reach a mutually beneficial outcome. | 我们的目标是以透明和灵活的方式达成双赢结果。 |
| Based on everything discussed so far, can you confirm whether the 10% discount is achievable? | 根据目前讨论的所有内容，能否确认 10% 的折扣可以实现？ |
| I'll need internal confirmation, but in principle that works. | 我还需要内部确认，但原则上这样可行。 |
| We're confident this partnership will be successful and mutually beneficial. | 我们相信这次合作会成功且互利。 |
| Longer payment terms are essential for our cash flow planning. | 更长的账期对我们的现金流规划至关重要。 |
| We can maintain buffer stock for critical items to prevent disruptions. | 我们可以为关键物料保留缓冲库存，避免供应中断。 |
| Plus or minus 15% flexibility on monthly forecasts without penalties. | 月度预测可上下浮动 15%，且不罚。 |
| We propose joint quality audits twice a year. | 我们建议每年做两次联合质量稽核。 |
