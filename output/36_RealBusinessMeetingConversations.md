## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| I don't want us leaving this call with assumptions instead of clarity. | 我不想大家带着猜测而不是明确的结论离开这场会。 |
| Owners and deadlines now will save us from confusion later. | 现在定好负责人和截止时间，后面就不会乱。 |
| That works as long as finance actually hits that deadline. | 只要财务真能赶上这个截止时间，这样安排就行。 |
| I'll take ownership of the FAQ. | 常见问题文档由我来负责。 |
| I'll draft the first version and share it by end of day Wednesday. | 我先起草第一版，周三下班前发给大家。 |
| Make sure all decision makers are included, not just observers. | 要确保所有决策人都在场，而不只是旁听的人。 |
| What's the mitigation plan? | 缓解方案是什么？ |
| I'll ask the vendor for an uptime and incident report within 24 hours. | 我会要求供应商在 24 小时内给出正常运行时间和故障报告。 |
| Any request that sounds small but requires code changes is still out of scope. | 任何听起来很小、但需要改代码的需求，仍然不在本次范围内。 |
| If someone believes a change is critical, it must be escalated with a clear business case. | 如果有人认定某改动很关键，必须带着明确业务理由上报。 |
| If something is delayed, explain why and what happens next. | 有延误就说明原因和下一步怎么办。 |
| Let's touch base tomorrow morning to confirm progress. | 明早我们再碰一下，确认进度。 |
| And you'll send the recap within 15 minutes? | 你会在 15 分钟内把纪要发出来吗？ |
| I'll also attach the decision log so the context is preserved. | 我还会附上决策记录，把背景保留下来。 |
| Now let's talk about the go or no-go decision. | 现在我们来谈做还是不做的决断。 |
| That's a hard lock. No new features, no scope additions. | 这是硬性冻结，不再加新功能、不再扩范围。 |
