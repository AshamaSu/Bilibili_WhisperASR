# 听力训练方法 · 商务英语播客

> 适用材料：67 集商务英语播客（每集 md 词表 + transcripts/ 的 SRT）。目标：从「每句都懂」进阶到「每段能说出讲了什么」。

## 1. 核心目标与预期

- **旧目标**：每句都懂 → 工作记忆被逐句解码占满，段落结构丢失，越听越累
- **新目标**：每段能说出讲了什么（口头复盘，见 §4.3）
- **听懂率预期 70~80%**：接受 25~30% 的信息（含生词）自然流过，不追
- 5 天能「勉强跟上」= 材料难度合适（i+1 区间上沿），问题只在方法
- 进度以 4~6 周为评估周期，不用当日感觉评分（见 §6）

## 2. 听的时候：三条铁律

1. **不停顿**：遇生词不暂停、不回拖、不现场查，让声音继续流；只抓数字、逻辑词（but/so/because）、重复出现的词
2. **不做现场翻译**：关掉「这句什么意思 → 对应哪个中文」的分析回路，这是漏听的直接原因
3. **只做 1 秒级标记**：确要记，就在句子边界记个音（如 stakeh?lder），绝不中断播放

## 3. 一集四遍流程

| 遍次 | 动作 | 目标 | 不要做的事 |
|---|---|---|---|
| 1 · 裸听 | 原速完整听，不停顿 | 抓大意，听懂 70%+，心里标记没听懂的位置 | 不停顿、不回拖 |
| 2 · 带词表听 | 先看 md 核心词/句式表预热，再听 | 预热词在真实语流中被认出来 | 不盯着词表听 |
| 3 · 带 SRT 精听 | 逐段听 + 看稿比对，抄生词卡 | 沉淀生词、核对第 1 遍的标记 | 不整段重听 |
| 4 · 隔天裸听 | 原速重听同一集 | 验收漏听是否减少——这一遍才是验收 | 不看稿 |

## 4. 三个动作（对应「注意力预算图」的文字版）

注意力预算对比：

| 模式 | 逐句解码/现场翻译 | 其他 |
|---|---|---|
| 现在（句级监听） | ≈ 80% | 20% |
| 目标（结构监听） | 路标词+段落结构 45% ｜ 关键词捕捉 30% ｜ 生词不追 25% | — |

### 4.1 听前 · 激活预测（30 秒）

看标题 + 核心词表，花半分钟猜：这期大概讲什么？可能出现哪些表达？

- 作用：让大脑提前挂好钩子，听到相关内容时是「验证」而非「从零解码」，省反应时间

### 4.2 听中 · 只抓路标

刻意只听**话语标记词 + 每句的实词名词**，其余放过。路标词清单：

| 功能 | 短语 |
|---|---|
| 话题开启 | let's talk about / today we're looking at / the first thing is |
| 转折递进 | but here's the thing / the problem is / on top of that |
| 举例解释 | for example / for instance / in other words |
| 收束总结 | so basically / the bottom line is / to sum up |

- 双人播客的提问句（*So, how do I...?*）本身是天然路标：听到提问就知道「要展开一个方法了」

### 4.3 段后 · 口头复盘

每 3~5 分钟暂停一次，用 1~2 句中文或英文说出这段讲了什么。

- 说得出 → 继续
- 说不出 → **只重听这一段**（这是唯一值得重听的情况，与「回拖补漏听」有本质区别）
- 这是唯一强制把注意力从句子层拉到段落层的训练，是三个动作里最关键的一个

## 5. 生词处理（听时不追，听后精选）

**入选标准**（第 3 遍精听时执行）：

- 出现 ≥2 次 或 影响句子理解 → 必学
- 只出现 1 次、不影响大意 → 放过（i+1 原则，超纲词不追）
- 每集控制在 8~12 个，宁缺毋滥

**生词卡练法**（多数词是「阅读词汇」：看得懂、听不懂）：

- 练「**听发音 → 立刻说中文意思**」，1~2 秒内反应出来才算过
- **不默写**——目标是建立 声音→意义 直连，而不是 声音→拼写→中文 的慢通路
- 卡片字段：词 | 音标 | 释义 | 集号 | 时间戳

## 6. 进度评估与习惯

- **量化方式**：4~6 周后重听第 01 集，对比首次裸听能复述出多少内容，这是唯一有效的进度指标
- 单集高强度注意力极限约 40 分钟，掉线时拆两次听，不丢人
- **不长期依赖** 0.75x 变速或对照 SRT 听——它们只用于第 3 遍精听；裸听那两遍必须原速

## 附：一集流程速查

```
看标题+词表猜内容（30s）→ 裸听不停顿 → 段后口头复盘（说不出才重听该段）
→ 带词表听 → 带 SRT 精听抄生词卡（8~12 个）→ 隔天原速裸听验收
```
