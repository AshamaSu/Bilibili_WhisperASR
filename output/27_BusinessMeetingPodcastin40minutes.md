## 3. 词句翻译

| 英文 | 中文 |
|---|---|
| We can also prepare backup examples in case they push back. | 我们还可以准备备用案例，以防他们反驳。 |
| So that phrase, in case they push back, is really about anticipating conflict. | 「以防他们反驳」这个说法，本质上是在预判冲突。 |
| I will check their bandwidth. | 我会确认一下他们的精力/人手够不够。 |
| I will update the risk register. | 我会更新风险登记表。 |
| A recap email goes out right after the meeting. | 会议一结束就发纪要邮件。 |
| And they proactively tell stakeholders if there's going to be a delay. | 如果会延期，他们会主动告知相关方。 |
| Transparency helps avoid confusion and builds trust. | 透明能避免误解、建立信任。 |
| Transparency is the currency of trust in remote or complex teams. | 在远程或复杂团队中，透明就是信任的通货。 |
| In a crisis, silence is terrifying. | 危机时刻，沉默最可怕。 |
| If you can say, I'm glad you asked, let me pull up this backup slide. | 你可以说：「问得好，我调出备用幻灯片。」 |
| It depersonalizes the potential conflict. | 它让潜在的冲突「对事不对人」。 |
| It prevents that awkward silence. | 它避免了尴尬的冷场。 |
| Provides a learning loop before scaling. | 在扩大规模前先建立复盘循环。 |
| This team makes every single message count. | 这个团队让每条信息都有分量。 |
| It's like a rapid fire checklist, boom, boom, boom. | 就像快节奏地过清单，一项接一项。 |
